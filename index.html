Import Roca CSV Files

Required CSV Filename Format

Every uploaded file must be named Batch-[batch number].csv (for example: Batch-19.csv or Batch-20.csv).

The Codex reads the batch number directly from each file's name, labels Bin1 → B-[batch#]a and Bin2/Bin3 → B-[batch#]b, and rejects files with any other name.

Google Sheet Sync (Batches-Combined MAIN)

How The Codex Works with Batches-Combined MAIN

  • Roca Bin Auto-Labeling: Uploading Batch-19.csv automatically labels Bin1 as B-19a and Bin2/Bin3 as B-19b.
  • Variant Name Normalization: Parenthetical suffixes such as Sword of the Meek (Schematic) or Hymn to Tourach (Hoover) automatically match Sword of the Meek and Hymn to Tourach.
  • 7-Day Recently Deleted Recovery: Deleted cards move to Recently Deleted for 7 days and can be restored with one click.
